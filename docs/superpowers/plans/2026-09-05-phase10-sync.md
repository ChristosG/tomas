# Dimitris' App — Phase 10 (Sync) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Chris and Dimitris' father install the same APK on their own phones as caregivers, add words and voices from home, and watch progress, through a tiny self-hosted sync server on one of their own web servers. No third-party backend.

**Architecture:** A dependency-free Node 22 server (`server/`) storing a row log (JSON lines, last-write-wins per table+id) and media by SHA-256, behind a bearer token and the owners' TLS reverse proxy. In the app, a `SyncEngine` pushes rows changed since the last push (paths rewritten to `media://<sha256>`, files uploaded), pulls rows since the last server sequence (media downloaded, paths rewritten back), and merges last-write-wins. A first-run role screen decides whether a phone is Dimitris' or a caregiver's.

**Tech Stack:** Node 22 built-ins only (`node:http`, `node:fs`, `node:crypto`, `node:test`); Kotlin `HttpURLConnection` (no new client library) + Gson.

**Spec:** `docs/superpowers/specs/2026-09-05-dimitris-app-design.md` (§7 phase 10, §5 sync contract)

## Global Constraints

- Sync contract: every table row carries `id`, `updatedAt`, `deleted`; `attempts`, `error_logs` and `script_lines` are append-only (union); other tables merge last-write-wins on `updatedAt` (ties keep local). Schedules key on `(itemId, module)` → sync id `"$itemId:$module"`.
- Protocol: `POST /v1/push` `{rows:[{table,row}]}` → `{seq}`; `GET /v1/pull?since=<seq>&limit=500` → `{rows:[{seq,table,row}],seq}`; `HEAD|PUT|GET /v1/media/<sha256>`; `GET /v1/health`. Every request except health carries `Authorization: Bearer <token>`.
- Media: outgoing `imagePath`/`path` values become `media://<sha256>` after upload; incoming `media://` values are downloaded into `photosDir`/`recordingsDir` as `<sha256>.<jpg|m4a>` and rewritten to absolute paths. Missing media never blocks a row.
- Settings: `syncUrl` (DataStore), `syncToken` (SecretStore), `deviceRole` (DIMITRIS default / CAREGIVER), `syncCursor` (server seq), `syncPushedUpTo` (updatedAt). Sync runs on caregiver tap and at app start when configured; Dimitris' phone never shows sync UI.
- Greek-only UI; commits `feat(phase10): ...` with the Co-Authored-By trailer; server code English (developer-facing), README in English with a Greek summary for the father.

- [ ] `store.mjs`: `class Store(dir)` — loads `rows.jsonl` into `Map<table, Map<id, {seq,row}>>` and `seq`; `apply(table, row)` (append-only tables always append; others only if `row.updatedAt > existing.updatedAt`), each accepted row gets `++seq` and is appended to the file; `since(seq, limit)`; media `has(sha)`, `put(sha, stream)` (verifies the hash while writing to `media/<sha>.tmp`, renames), `path(sha)`.
